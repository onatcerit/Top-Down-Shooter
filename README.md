# Top-Down Shooter (Java)

A wave-based top-down shooter game developed in **Java** using **Swing/AWT**.  
The objective is to survive against increasingly difficult zombie waves using various weapons, maps, and environmental effects.

## Features
- Wave-based zombie survival gameplay
- Multiple enemy types with distinct behaviors
- Progressive weapon unlock system
- Three playable maps with obstacles
- Dynamic weather system with sound effects
- Save & load functionality
- Multiple menus (Main, Pause, Game Over, Victory)

## Enemy Types
- Normal Zombie (melee)
- Crawler Zombie (fast, low profile)
- Tank Zombie (high durability)
- Spitter Zombie (ranged attack)

## Weapons
- Pistol
- Rifle
- Shotgun
- Sniper Rifle
- Rocket Launcher

## Technologies
- Java
- Swing / AWT
- Object-Oriented Programming (OOP)
